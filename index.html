意義（詞性）例句（出處）
助詞，的
以子「之」矛，陷子「之」盾（第21課，課本標註）

動詞，到、往
衣冠而「之」市（第25課，注釋⑥、課本標註）
代詞
譽「之」曰（指盾／矛）（第21課，課本標註）
吏捕得「之」（指攫金的人）（第25課，課本標註）

「之」是助詞時，多翻成「的」或不必翻譯；是動詞時，意思是「到、往」；是代詞時，要依上下文找出它指的人、事、物。

意義（詞性）例句（出處）
向
晉平公問「於」師曠（第22課，課本標註）

苛政猛「於」虎（比）、己所不欲，勿施「於」人（給）（複習，第18課）

「於」的常見用法：1.對於　2.向　3.在　4.比　5.給　6.被（置於動詞之後，表示被動）（課本標註，見11–20課整理）。

第21課　自相矛盾　《韓非子》

詞語意思
鬻賣
盾古兵器，用來抵禦敵人的刀劍或戈矛的刺擊，具防禦作用
矛古兵器，長柄，有青銅或鐵製的利刃，用來刺、戳穿敵人，具攻擊作用
譽誇讚
陷刺穿
或有人
何如怎麼樣
應回答
弗不

原文：楚人有鬻盾與矛者，譽之曰：「吾盾之堅，物莫能陷也。」又譽其矛曰：「吾矛之利，於物無不陷也。」或曰：「以子之矛，陷子之盾，何如？」其人弗能應也。

「矛」與「盾」一攻一守，性質相反：不可陷之盾與無不陷之矛，不可能同時存在，這正是矛盾之所在。

成語「自相矛盾」：比喻言語或行事前後不一致，互相牴觸，無法自圓其說。

第22課　師曠論學　《說苑》

詞語意思
師曠春秋時期晉國樂師，字子野，雙目失明，以精通音律著稱
暮晚
炳燭點燃蠟燭
安豈、怎麼（反問語氣）
孰與比……怎麼樣
昧行在黑暗中行走
盲臣師曠自稱

原文：晉平公問於師曠曰：「吾年七十，欲學，恐已暮矣。」師曠曰：「何不炳燭乎？」平公曰：「安有為人臣而戲其君乎？」師曠曰：「盲臣安敢戲其君乎？臣聞之：少而好學，如日出之陽；壯而好學，如日中之光；老而好學，如炳燭之明。炳燭之明，孰與昧行乎？」平公曰：「善哉！」

補充（墨子・所染）：蓬生麻中，不扶而直；白沙在涅，與之俱黑。入鮑魚之肆，久而不聞其臭；入芝蘭之室，久而不聞其香。染於蒼則蒼，染於黃則黃——比喻人的習性會因環境影響而改變，近朱者赤，近墨者黑。

成語「炳燭之明」：比喻年老仍好學不倦。

第23課　阿豺折箭　《魏書》

詞語意思
阿豺南北朝時期西北邊境少數民族吐谷渾的首領
汝你
俄而一會兒
母弟同母弟弟
汝曹你們
摧折斷
戮力合力
社稷國家的代稱

原文：阿豺有子二十人，臨終謂諸子曰：「汝等各獻吾一支箭。」一一折斷之。又謂母弟慕利延曰：「汝取一支箭折之。」慕利延折之。阿豺曰：「汝取十九支箭折之。」延不能折。阿豺乃曰：「汝曹知否？單者易折，眾則難摧。戮力一心，然後社稷可固。」

智慧諺語：一虎難敵眾犬；三個臭皮匠，勝過一個諸葛亮——比喻集合眾人的思考、討論，力量可以獲得更廣大的效益。

成語「戮力同心」：比喻齊心合力。

第24課　名落孫山　《過庭錄》

詞語意思
孫山宋朝吳地人，滑稽才子
滑稽詼諧有趣的言語或動作
赴舉參加鄉試
解名鄉試錄取的名次；泛指考中舉人者的名字
失意不如意，指未被錄取

宋朝時吳地有個人名叫孫山，是個幽默風趣又有才氣的讀書人。有一年，他和同鄉人的兒子一起到別郡參加鄉試，發榜後，孫山僥倖考中榜末，同鄉人的兒子卻落榜了。孫山先回到家，同鄉人問起自己兒子考得如何，孫山回答：「舉人榜單上最後一名是孫山，您的兒子還落在孫山的後面呢！」

成語「名落孫山」：比喻投考未被錄取，榜上無名。

文學常識（科舉制度）：童生 →（縣、府試）→ 秀才 →（鄉試）→ 舉人（第一名稱解元）→（會試）→ 貢士（第一名稱會元）→（殿試）→ 進士（第一名稱狀元）。古人所謂「連中三元」，就是指在鄉試、會試、殿試中都考取第一名。

第25課　齊人攫金　《列子》

詞語意思
欲想要
清旦清早
衣冠穿衣戴帽
適到
鬻出售
攫抓取、搶奪
徒只

原文：昔齊人有欲金者，清旦，衣冠而之市，適鬻金者之所，因攫其金而去。吏捕得之，問曰：「人皆在焉，子攫人之金何？」對曰：「取金之時，不見人，徒見金。」

補充成語：目不見睫（比喻人無自知之明，不能看見自己的過失）、玩物喪志（一味玩賞無益的器物，因而消磨人的志向）、鼠目寸光（形容人目光短淺，識見狹小）、利慾薰心（被利慾迷惑，使得理智昏亂）、鋌而走險（在窮途末路或受逼迫時，採取冒險行動或不正當的行為）。

名句精讀：《三國志》：「勿以惡小而為之，勿以善小而不為。」／《孟子》：「富貴不能淫，貧賤不能移，威武不能屈，此之謂大丈夫。」

虛字練習（課文中的虛字）

  1. 「汝取十九支箭折之」的「汝」，與下列哪一個字的意思「不同」？
    汝＝爾＝若＝卿，都是「你」；吾是「我」。
  2. 「以子之矛，陷子之盾」的「之」，意思是？
    以子之矛＝用你的矛，「之」是助詞，相當於「的」。
  3. 「衣冠而之市」的「之」，意思是？
    衣冠而之市＝穿好衣服戴好帽子後前往市集，「之」是動詞，到、往。
  4. 「吏捕得之」的「之」，指的是誰？
    巡吏逮捕的，是那個伸手搶奪金子的齊人。
  5. 「晉平公問於師曠」的「於」，意思是？
    問於師曠＝向師曠請教。
  6. 「以子之矛，陷子之盾，何如？」的「何如」，意思是？
    何如＝怎麼樣，用來詢問結果或看法。
  7. 「其人弗能應也」的「弗」，意思是？
    弗＝不，其人弗能應也＝那個人不能夠回答。
  8. 「俄而命母弟慕利延曰」的「俄而」，意思是？
    俄而＝一會兒，表示時間很短。
  9. 阿豺對眾子說「汝曹知否」，「汝曹」是指誰？
    汝曹＝你們，指阿豺的眾多兒子。
  10. 「清旦，衣冠而之市」的「清旦」，意思是？
    清旦＝清早（注釋②）。
  11. 「不見人，徒見金」的「徒」，意思是？
    徒：只（注釋⑩）。取金之時，眼中只看見金子。
  12. 「師曠曰：『何不炳燭乎？』」的意思是？
    炳燭＝點燃蠟燭；何不……乎＝為什麼不……呢。
  13. 「老而好學，如炳燭之明，孰與昧行乎？」的「孰與」，意思是？
    孰與：比……怎麼樣，用來比較兩件事的優劣。
  14. 「盲臣安敢戲其君乎？」的「安」，意思是？
    安：豈、怎麼，用來加強反問語氣。
  15. 下列「之」字用法，何者與其他三者「不同」？
    「衣冠而之市」的「之」是動詞（到、往）；其餘三者的「之」都是助詞（的）。
  16. 下列文句所表現的語氣，何者是「反問」？
    「安有為人臣而戲其君乎」用反問語氣，強調自己絕不敢戲弄君主。

成語、修辭與文學常識

  1. 後人以「自相矛盾」比喻什麼？
    自相矛盾：說話或做事前後衝突，不能自圓其說（課本標註）。
  2. 「少而好學，如日出之陽；壯而好學，如日中之光；老而好學，如炳燭之明」運用了哪兩種修辭？
    三句結構相同、依年齡層層推進，兼具排比與層遞。
  3. 後人以「炳燭之明」比喻什麼？
    師曠以點燭之光比喻老年好學，仍能照亮前路（課本標註）。
  4. 「單者易折，眾則難摧」與下列哪一句意思最接近？
    單一的箭容易折斷，聚集起來就難以摧毀，意近「眾志成城」。
  5. 後人以「名落孫山」比喻什麼？
    孫山雖是榜末，仍算考中；「名落孫山」則專指落榜、未被錄取。

第21課　自相矛盾　《韓非子》

  1. 楚人先誇讚自己的盾牌堅固無比，接著又誇讚自己的長矛銳利無比，這樣的言論顯示了什麼？
    楚人先說「物莫能陷」，又說「於物無不陷」，兩句話互相矛盾。
  2. 「以子之矛，陷子之盾，何如？」這句話的作用是？
    有人用楚人自己的說法反問他，使矛盾之處無所遁形。
  3. 根據這則寓言，後人以「自相矛盾」比喻什麼樣的人？
    楚人先譽盾又譽矛，前後說法無法並存，正是「自相矛盾」。
  4. 「其人弗能應也」的「應」，意思是？
    應：回答。楚人被質問後，答不出話來。

第22課　師曠論學　《說苑》

  1. 在本文中，晉平公起初認為自己？
    平公說：「吾年七十，欲學，恐已暮矣」，認為自己年紀已大，學習恐怕太晚了。
  2. 從師曠對平公說的話中可以看出，他認為最重要的是？
    師曠以「少而好學」「壯而好學」「老而好學」層層說明，強調的是願不願意學習的心，而非年紀。
  3. 下列哪句話最切合本文主旨？
    本文說明即使年老，仍可以透過學習照亮自己，正是「活到老，學到老」。
  4. 根據本文，後人便以「炳燭之明」來比喻？
    師曠以點燃蠟燭比喻晚年學習，雖光亮微弱，仍勝過在黑暗中摸索前行。

第23課　阿豺折箭　《魏書》

  1. 下列哪一句最貼近本文的主旨？
    阿豺藉折箭的比喻，說明眾人團結一心，力量就無法被摧毀。
  2. 阿豺臨終前教誨眾子折箭，是希望？
    阿豺說「戮力一心，然後社稷可固」，希望眾子同心協力，才能保國安邦。
  3. 「單者易折，眾則難摧」，意思最接近下列哪一個成語？
    單一的箭容易折斷，聚在一起卻難以摧毀，意近「眾志成城」。
  4. 「俄而」的意思接近「不久」，下列何者「不可以」替換？
    剎那、須臾、頃刻都表示「一會兒、很短的時間」；三人成虎則比喻謠言惑眾，與時間無關。

第24課　名落孫山　《過庭錄》

  1. 本文中提到到別郡參加鄉試的人，一共有幾位？
    文中提到孫山與同鄉人的兒子，兩人一同赴別郡應試。
  2. 孫山用「解名盡處是孫山，賢郎更在孫山外」回答鄉人，是為了說明什麼？
    孫山幽默委婉地告知鄉人：自己是榜上最後一名，鄉人之子則連孫山都比不上，已經落榜了。
  3. 本文主要是在敘述哪一種情境？
    文章重點在孫山如何機智、幽默地把「落榜」這件難以啟齒的事說出口。
  4. 後人以「名落孫山」比喻什麼？
    「名落孫山」即比喻應考不中、榜上無名。

第25課　齊人攫金　《列子》

  1. 本文的主旨最可能是？
    齊人「取金之時，不見人，徒見金」，正是被利慾蒙蔽心智的寫照。
  2. 「攫金者」的「攫」是指？
    攫：抓取、搶奪（注釋⑦）。
  3. 「不見人，徒見金」的「徒」，意思是？
    徒：只（注釋⑩）。齊人眼中只看見金子，看不見在場的人。
  4. 「吏捕得之」的「之」是指？
    巡吏逮捕的對象，是那個伸手搶奪金子後逃跑的齊人。

13A孰與：比……怎麼樣，用來比較兩件事的優劣。
14B安：豈、怎麼，用來加強反問語氣。
15C「衣冠而之市」的「之」是動詞（到、往）；其餘三者的「之」都是助詞（的）。
16D「安有為人臣而戲其君乎」用反問語氣，強調自己絕不敢戲弄君主。

題號答案解析
1C自相矛盾：說話或做事前後衝突，不能自圓其說（課本標註）。
2B三句結構相同、依年齡層層推進，兼具排比與層遞。
3A師曠以點燭之光比喻老年好學，仍能照亮前路（課本標註）。
4D單一的箭容易折斷，聚集起來就難以摧毀，意近「眾志成城」。
5B孫山雖是榜末，仍算考中；「名落孫山」則專指落榜、未被錄取。

參、課文選擇題（題號：課次－題號）

題號答案解析
21－1B楚人先說「物莫能陷」，又說「於物無不陷」，兩句話互相矛盾。
21－2A有人用楚人自己的說法反問他，使矛盾之處無所遁形。
21－3C楚人先譽盾又譽矛，前後說法無法並存，正是「自相矛盾」。
21－4A應：回答。楚人被質問後，答不出話來。
22－1B平公說：「吾年七十，欲學，恐已暮矣」，認為自己年紀已大，學習恐怕太晚了。
22－2D師曠以「少而好學」「壯而好學」「老而好學」層層說明，強調的是願不願意學習的心，而非年紀。
22－3B本文說明即使年老，仍可以透過學習照亮自己，正是「活到老，學到老」。
22－4B師曠以點燃蠟燭比喻晚年學習，雖光亮微弱，仍勝過在黑暗中摸索前行。
23－1A阿豺藉折箭的比喻，說明眾人團結一心，力量就無法被摧毀。
23－2B阿豺說「戮力一心，然後社稷可固」，希望眾子同心協力，才能保國安邦。
23－3B單一的箭容易折斷，聚在一起卻難以摧毀，意近「眾志成城」。
23－4D剎那、須臾、頃刻都表示「一會兒、很短的時間」；三人成虎則比喻謠言惑眾，與時間無關。
24－1B文中提到孫山與同鄉人的兒子，兩人一同赴別郡應試。
24－2A孫山幽默委婉地告知鄉人：自己是榜上最後一名，鄉人之子則連孫山都比不上，已經落榜了。
24－3B文章重點在孫山如何機智、幽默地把「落榜」這件難以啟齒的事說出口。
24－4D「名落孫山」即比喻應考不中、榜上無名。
25－1D齊人「取金之時，不見人，徒見金」，正是被利慾蒙蔽心智的寫照。
25－2C攫：抓取、搶奪（注釋⑦）。
25－3A徒：只（注釋⑩）。齊人眼中只看見金子，看不見在場的人。
25－4A巡吏逮捕的對象，是那個伸手搶奪金子後逃跑的齊人。
