第21課　自相矛盾　《韓非子》

📜 原文

楚人有鬻盾與矛者，譽之曰：「吾盾之堅，物莫能陷也。」又譽其矛曰：「吾矛之利，於物無不陷也。」或曰：「以子之矛，陷子之盾，何如？」其人弗能應也。

📖 注釋

①鬻：賣　②盾：古兵器，用來抵禦敵人的刀劍或戈矛的刺擊，具防禦作用　③矛：古兵器，長柄，有青銅或鐵製的利刃，用來刺、戳穿敵人，具攻擊作用　④譽：誇讚　⑤陷：刺穿　⑥或：有人　⑦何如：怎麼樣　⑧應：回答　⑨弗：不

🗣 語譯

楚國有個人同時賣盾牌和長矛，他誇耀自己的盾牌說：「我的盾牌非常堅固，沒有東西能刺穿它。」又誇耀自己的矛說：「我的矛非常鋒利，沒有東西刺不穿。」有人問他：「用你的矛來刺你的盾，結果會怎麼樣呢？」那個人無法回答。

📚 成語教室

「矛」與「盾」一攻一守，性質相反：不可陷之盾與無不陷之矛，不可能同時存在，這正是矛盾的由來。成語「自相矛盾」：比喻言語或行事前後不一致，互相牴觸，無法自圓其說。

📝 隨堂練習

  1. 楚人先誇讚自己的盾牌堅固無比，接著又誇讚自己的長矛銳利無比，這樣的言論顯示了什麼？
    楚人先說「物莫能陷」，又說「於物無不陷」，兩句話互相矛盾。
  2. 「以子之矛，陷子之盾，何如？」這句話的作用是？
    有人用楚人自己的說法反問他，使矛盾之處無所遁形。
  3. 根據這則寓言，後人以「自相矛盾」比喻什麼樣的人？
    楚人先譽盾又譽矛，前後說法無法並存，正是「自相矛盾」。
  4. 「其人弗能應也」的「應」，意思是？
    「應」字依語境有多種意思：(A)回答——本文「其人弗能應也」即指楚人答不出話來，為正確答案。(B)對付、因應——如「隨機應變」的「應」。(C)適合、相稱——如「得心應手」「應景」的「應」。(D)附和、呼應——如「一唱一應」「裡應外合」的「應」。

第22課　師曠論學　《說苑》

📜 原文

晉平公問於師曠曰：「吾年七十，欲學，恐已暮矣。」師曠曰：「何不炳燭乎？」平公曰：「安有為人臣而戲其君乎？」師曠曰：「盲臣安敢戲其君乎？臣聞之：少而好學，如日出之陽；壯而好學，如日中之光；老而好學，如炳燭之明。炳燭之明，孰與昧行乎？」平公曰：「善哉！」

📖 注釋

①師曠：春秋時期晉國樂師，字子野，雙目失明，以精通音律著稱　②暮：晚　③炳燭：點燃蠟燭　④安：豈、怎麼（反問語氣）　⑤孰與：比……怎麼樣　⑥昧行：在黑暗中行走　⑦盲臣：師曠自稱

🗣 語譯

晉平公問師曠說：「我已經七十歲了，想要學習，恐怕已經太晚了。」師曠說：「為什麼不點亮蠟燭呢？」平公說：「哪有身為臣子卻戲弄君主的呢？」師曠說：「我這瞎眼的臣子怎敢戲弄君主呢？我聽說：年少時好學，就像初升的太陽散發光芒；壯年時好學，就像正午的陽光普照；老年時好學，就像點燃蠟燭照明。點蠟燭的光亮，比起在黑暗中摸索前行，哪一個更好呢？」平公說：「說得好啊！」

📚 名句精讀

《墨子・所染》：「蓬生麻中，不扶而直；白沙在涅，與之俱黑。入鮑魚之肆，久而不聞其臭；入芝蘭之室，久而不聞其香。染於蒼則蒼，染於黃則黃。」說明環境對人習性的潛移默化，與「近朱者赤，近墨者黑」意思相同。

📝 隨堂練習

  1. 在本文中，晉平公起初認為自己？
    平公說：「吾年七十，欲學，恐已暮矣」，認為自己年紀已大，學習恐怕太晚了。
  2. 從師曠對平公說的話中可以看出，他認為最重要的是？
    師曠以「少而好學」「壯而好學」「老而好學」層層說明，強調的是願不願意學習的心，而非年紀。
  3. 下列哪句話最切合本文主旨？
    本文說明即使年老，仍可以透過學習照亮自己，正是「活到老，學到老」。
  4. 根據本文，後人便以「炳燭之明」來比喻？
    師曠以點燃蠟燭比喻晚年學習，雖光亮微弱，仍勝過在黑暗中摸索前行。

第23課　阿豺折箭　《魏書》

📜 原文

阿豺有子二十人，臨終謂諸子曰：「汝等各獻吾一支箭。」一一折斷之。又謂母弟慕利延曰：「汝取一支箭折之。」慕利延折之。阿豺曰：「汝取十九支箭折之。」延不能折。阿豺乃曰：「汝曹知否？單者易折，眾則難摧。戮力一心，然後社稷可固。」

📖 注釋

①阿豺：南北朝時期西北邊境少數民族吐谷渾的首領　②汝：你　③俄而：一會兒　④母弟：同母弟弟　⑤汝曹：你們　⑥摧：折斷　⑦戮力：合力　⑧社稷：國家的代稱

🗣 語譯

阿豺有二十個兒子，臨終前對眾子說：「你們每人獻給我一支箭。」他把箭一一折斷。又對同母弟弟慕利延說：「你拿一支箭把它折斷。」慕利延折斷了。阿豺說：「你拿十九支箭一起折斷它。」慕利延無法折斷。阿豺於是說：「你們知道了嗎？單獨一支容易折斷，聚集起來就難以摧毀。只要齊心合力，國家就能穩固。」

📚 智慧諺語

一虎難敵眾犬；三個臭皮匠，勝過一個諸葛亮——比喻集合眾人的思考、討論，力量可以獲得更廣大的效益。成語「戮力同心」：比喻齊心合力。

📝 隨堂練習

  1. 下列哪一句最貼近本文的主旨？
    阿豺藉折箭的比喻，說明眾人團結一心，力量就無法被摧毀。
  2. 阿豺臨終前教誨眾子折箭，是希望？
    阿豺說「戮力一心，然後社稷可固」，希望眾子同心協力，才能保國安邦。
  3. 「單者易折，眾則難摧」，意思最接近下列哪一個成語？
    單一的箭容易折斷，聚在一起卻難以摧毀，意近「眾志成城」。
  4. 「俄而」的意思接近「不久」，下列何者「不可以」替換？
    剎那、須臾、頃刻都表示「一會兒、很短的時間」；三人成虎則比喻謠言惑眾，與時間無關。

第24課　名落孫山　《過庭錄》

📜 原文

吳人孫山，滑稽才子也。赴舉他郡，鄉人託以子偕往。發榜，山幸而中，鄉人之子失意。山先歸，鄉人問其子得失，山曰：「解名盡處是孫山，賢郎更在孫山外。」

📖 注釋

①孫山：宋朝吳地人，滑稽才子　②滑稽：詼諧有趣的言語或動作　③赴舉：參加鄉試　④解名：鄉試錄取的名次；泛指考中舉人者的名字　⑤失意：不如意，指未被錄取

🗣 語譯

宋朝時吳地有個人名叫孫山，是個幽默風趣又有才氣的讀書人。有一年，他和同鄉人的兒子一起到別郡參加鄉試，發榜後，孫山僥倖考中榜末，同鄉人的兒子卻落榜了。孫山先回到家，同鄉人問起自己兒子考得如何，孫山回答：「舉人榜單上最後一名是孫山，您的兒子還落在孫山的後面呢！」

📚 文學常識

科舉制度：童生 →（縣、府試）→ 秀才 →（鄉試）→ 舉人（第一名稱解元）→（會試）→ 貢士（第一名稱會元）→（殿試）→ 進士（第一名稱狀元）。古人所謂「連中三元」，就是指在鄉試、會試、殿試中都考取第一名。成語「名落孫山」：比喻投考未被錄取，榜上無名。

📝 隨堂練習

  1. 本文中提到到別郡參加鄉試的人，一共有幾位？
    文中提到孫山與同鄉人的兒子，兩人一同赴別郡應試。
  2. 孫山用「解名盡處是孫山，賢郎更在孫山外」回答鄉人，是為了說明什麼？
    孫山幽默委婉地告知鄉人：自己是榜上最後一名，鄉人之子則連孫山都比不上，已經落榜了。
  3. 本文主要是在敘述哪一種情境？
    文章重點在孫山如何機智、幽默地把「落榜」這件難以啟齒的事說出口。
  4. 後人以「名落孫山」比喻什麼？
    「名落孫山」即比喻應考不中、榜上無名。

第25課　齊人攫金　《列子》

📜 原文

昔齊人有欲金者，清旦，衣冠而之市，適鬻金者之所，因攫其金而去。吏捕得之，問曰：「人皆在焉，子攫人之金何？」對曰：「取金之時，不見人，徒見金。」

📖 注釋

①欲：想要　②清旦：清早　③衣冠：穿衣戴帽　④適：到　⑤鬻：出售　⑥攫：抓取、搶奪　⑦徒：只

🗣 語譯

從前齊國有個人想要得到金子，一天清早，他穿戴整齊，來到市集，到了賣金子的地方，趁機搶了金子就跑。官吏把他抓住，問他：「這麼多人都在場，你怎麼敢搶別人的金子呢？」他回答說：「我拿金子的時候，沒有看到人，只看到金子。」

📚 寫作技巧

本文以人物問答作結——「子攫人之金何？」「取金之時，不見人，徒見金。」不直接評論是非，而是藉荒謬的回答，讓讀者自己體會其中的諷刺與警惕。成語「齊人攫金」：比喻一心貪圖財利，見利而不見其他，因利慾薰心而不顧一切、不擇手段的人。

📝 隨堂練習

  1. 本文的主旨最可能是？
    齊人「取金之時，不見人，徒見金」，正是被利慾蒙蔽心智的寫照。
  2. 「攫金者」的「攫」是指？
    攫：抓取、搶奪（注釋⑥）。
  3. 「不見人，徒見金」的「徒」，意思是？
    徒：只（注釋⑦）。齊人眼中只看見金子，看不見在場的人。
  4. 後人以「齊人攫金」比喻什麼樣的人？
    (A)正確：「齊人攫金」正是形容一心貪圖財利、見利不見其他，因利慾薰心而不顧一切、不擇手段的人。(B)錯誤：齊人當眾搶奪他人財物，正好與「誠實可靠，堂堂正正」相反。(C)錯誤：齊人取金時「不見人，徒見金」，是不顧後果、莽撞行事，並非謹慎、瞻前顧後。(D)錯誤：齊人到市集的目的是伺機搶奪金子，不是單純逛街購物。

成語練習

以下題目不計入分數。

  1. 後人以「自相矛盾」比喻什麼？
    自相矛盾：說話或做事前後衝突，不能自圓其說（課本標註）。
  2. 「少而好學，如日出之陽；壯而好學，如日中之光；老而好學，如炳燭之明」運用了哪兩種修辭？
    三句結構相同、依年齡層層推進，兼具排比與層遞。
  3. 後人以「炳燭之明」比喻什麼？
    師曠以點燭之光比喻老年好學，仍能照亮前路（課本標註）。
  4. 「單者易折，眾則難摧」與下列哪一句意思最接近？
    單一的箭容易折斷，聚集起來就難以摧毀，意近「眾志成城」。
  5. 後人以「名落孫山」比喻什麼？
    孫山雖是榜末，仍算考中；「名落孫山」則專指落榜、未被錄取。
  6. 「蓬生麻中，不扶而直；白沙在涅，與之俱黑」這段話，與下列哪一個成語最能表現「環境對人的影響」？
    蓬草生長在麻中會自然挺直，白沙混入黑泥也會變黑，正說明環境對人潛移默化的影響，意近「近朱者赤，近墨者黑」。

「於」的常見用法：1.對於　2.向　3.在　4.比　5.給　6.被（置於動詞之後，表示被動）（課本標註，見11–20課整理）。

選擇題（每題 5 分，共 80 分）。粗體加底線的字為題目所問的字。直接點選答案作答。

  1. 「汝取十九支箭折之」的「汝」，與下列哪一個字的意思「不同」？
    汝＝爾＝若＝卿，都是「你」；吾是「我」。
  2. 「以子之矛，陷子之盾」的「之」，意思是？
    以子之矛＝用你的矛，「之」是助詞，相當於「的」。
  3. 「衣冠而之市」的「之」，意思是？
    衣冠而之市＝穿好衣服戴好帽子後前往市集，「之」是動詞，到、往。
  4. 「吏捕得之」的「之」，指的是誰？
    巡吏逮捕的，是那個伸手搶奪金子的齊人。
  5. 「晉平公問於師曠」的「於」，意思是？
    問於師曠＝向師曠請教。
  6. 「以子之矛，陷子之盾，何如？」的「何如」，意思是？
    何如＝怎麼樣，用來詢問結果或看法。
  7. 「其人弗能應也」的「弗」，意思是？
    弗＝不，其人弗能應也＝那個人不能夠回答。
  8. 「俄而命母弟慕利延曰」的「俄而」，意思是？
    俄而＝一會兒，表示時間很短。
  9. 阿豺對眾子說「汝曹知否」，「汝曹」是指誰？
    汝曹＝你們，指阿豺的眾多兒子。
  10. 「清旦，衣冠而之市」的「清旦」，意思是？
    清旦＝清早（注釋②）。
  11. 「不見人，徒見金」的「徒」，意思是？
    徒：只（注釋⑦）。取金之時，眼中只看見金子。
  12. 「師曠曰：『何不炳燭乎？』」的意思是？
    炳燭＝點燃蠟燭；何不……乎＝為什麼不……呢。
  13. 「老而好學，如炳燭之明，孰與昧行乎？」的「孰與」，意思是？
    孰與：比……怎麼樣，用來比較兩件事的優劣。
  14. 「盲臣安敢戲其君乎？」的「安」，意思是？
    安：豈、怎麼，用來加強反問語氣。
  15. 下列「之」字用法，何者與其他三者「不同」？
    「衣冠而之市」的「之」是動詞（到、往）；其餘三者的「之」都是助詞（的）。
  16. 下列文句所表現的語氣，何者是「激問」？
    「安有為人臣而戲其君乎」用激問語氣，答案在問題的反面，藉此強調自己絕不敢戲弄君主。

貳、課文選擇題（題號：課次－題號）

題號答案解析
21－1B楚人先說「物莫能陷」，又說「於物無不陷」，兩句話互相矛盾。
21－2A有人用楚人自己的說法反問他，使矛盾之處無所遁形。
21－3C楚人先譽盾又譽矛，前後說法無法並存，正是「自相矛盾」。
21－4A「應」字依語境有多種意思：(A)回答——本文「其人弗能應也」即指楚人答不出話來，為正確答案。(B)對付、因應——如「隨機應變」的「應」。(C)適合、相稱——如「得心應手」「應景」的「應」。(D)附和、呼應——如「一唱一應」「裡應外合」的「應」。
22－1B平公說：「吾年七十，欲學，恐已暮矣」，認為自己年紀已大，學習恐怕太晚了。
22－2D師曠以「少而好學」「壯而好學」「老而好學」層層說明，強調的是願不願意學習的心，而非年紀。
22－3B本文說明即使年老，仍可以透過學習照亮自己，正是「活到老，學到老」。
22－4B師曠以點燃蠟燭比喻晚年學習，雖光亮微弱，仍勝過在黑暗中摸索前行。
23－1A阿豺藉折箭的比喻，說明眾人團結一心，力量就無法被摧毀。
23－2B阿豺說「戮力一心，然後社稷可固」，希望眾子同心協力，才能保國安邦。
23－3B單一的箭容易折斷，聚在一起卻難以摧毀，意近「眾志成城」。
23－4D剎那、須臾、頃刻都表示「一會兒、很短的時間」；三人成虎則比喻謠言惑眾，與時間無關。
24－1B文中提到孫山與同鄉人的兒子，兩人一同赴別郡應試。
24－2A孫山幽默委婉地告知鄉人：自己是榜上最後一名，鄉人之子則連孫山都比不上，已經落榜了。
24－3B文章重點在孫山如何機智、幽默地把「落榜」這件難以啟齒的事說出口。
24－4D「名落孫山」即比喻應考不中、榜上無名。
25－1D齊人「取金之時，不見人，徒見金」，正是被利慾蒙蔽心智的寫照。
25－2C攫：抓取、搶奪（注釋⑥）。
25－3A徒：只（注釋⑦）。齊人眼中只看見金子，看不見在場的人。
25－4A(A)正確：「齊人攫金」正是形容一心貪圖財利、見利不見其他，因利慾薰心而不顧一切、不擇手段的人。(B)錯誤：齊人當眾搶奪他人財物，正好與「誠實可靠，堂堂正正」相反。(C)錯誤：齊人取金時「不見人，徒見金」，是不顧後果、莽撞行事，並非謹慎、瞻前顧後。(D)錯誤：齊人到市集的目的是伺機搶奪金子，不是單純逛街購物。

參、成語練習

題號答案解析
1C自相矛盾：說話或做事前後衝突，不能自圓其說（課本標註）。
2B三句結構相同、依年齡層層推進，兼具排比與層遞。
3A師曠以點燭之光比喻老年好學，仍能照亮前路（課本標註）。
4D單一的箭容易折斷，聚集起來就難以摧毀，意近「眾志成城」。
5B孫山雖是榜末，仍算考中；「名落孫山」則專指落榜、未被錄取。
6A蓬草生長在麻中會自然挺直，白沙混入黑泥也會變黑，正說明環境對人潛移默化的影響，意近「近朱者赤，近墨者黑」。
